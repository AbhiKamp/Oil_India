# StrataSentry-NWIS Live Demonstration Package

This directory contains turnkey artifacts for demonstrating real-time drilling hazard detection, physics validation, and depth-aware RAG grounded retrieval.

---

## Artifacts

- **`sample_wcr.pdf`**: Sample scanned-style Well Completion Report for offset well MOR-118 documenting an actual hole pack-off in the Barail coal formation.
- **`synthetic_telemetry.csv`**: Time-series replay containing an annular pack-off anomaly progressing from baseline to severe pressure surge.
- **`synthetic_surveys.csv`**: 3D Minimum Curvature directional surveys for active well NHK-421.
- **`run_demo.sh`**: One-touch bash script launching the end-to-end incident scenario.
