## 2. Air-Gapped Rig-Site Edge Node Specification

### Hardware Sizing (Minimum Rig Edge Node):
- **Form Factor**: 2U Ruggedized Industrial Rackmount (MIL-STD-810H vibration and temperature resistant)
- **Processor**: AMD EPYC 7302P or Intel Xeon Silver 4314 (16 cores, 32 threads)
- **RAM**: 64 GB ECC DDR4
- **Storage**: 2x 1.92 TB NVMe SSD (Hardware RAID 1 for operational redundancy)
- **Network**: Dual redundant 10GbE copper LAN ports for rig floor instrumentation isolation
- **Power**: Dual hot-swap redundant power supplies connected to rig uninterruptible power supply (UPS)

### Software Container Stack:
- Linux Ubuntu 22.04 LTS Kernel 5.15 (RT PREEMPT real-time patch optional)
- Docker Engine 24.0+ with Docker Compose v2
- Microk8s / K3s lightweight Kubernetes (for multi-rig container orchestration)

## 3. Cryptographic Satellite Synchronization

When network bandwidth (VSAT / Inmarsat / Starlink) is available intermittently:
1. **Delta Extraction**: Local edge daemon (`infrastructure/edge-node/sync_daemon.py`) identifies newly committed telemetry chunks, directional surveys, and alert logs.
2. **Compression & Encryption**: Bundles are compressed using Zstandard (`zstd`) level 19 and encrypted using ChaCha20-Poly1305 with an ephemeral key exchanged via X25519.
3. **Integrity Validation**: Bundles carry an HMAC-SHA256 signature generated by the edge node's private hardware security module (HSM).
4. **Cloud Reconciliation**: The central gateway verifies signatures, decrypts the payload, and performs idempotent upserts into the central TimescaleDB and Qdrant clusters.

---

## 4. Disaster Recovery & Failover Protocol

- If the primary edge node suffers a hardware fault, a hot-standby passive node automatically takes over the virtual IP within 15 seconds.
- In the event of total server loss, the Driller HUD seamlessly falls back to local browser cache and direct serial NMEA/WITSML hardware fallback meters.
