# Before the Next Metre — on-screen narrative

**Status:** 141-second rough master uses these lines as timed on-screen captions, not spoken narration. Product segment is actual, recorded browser footage, accelerated 1.3× for pace. Explanatory geological layers are original graphics and labeled illustrative. All demonstrations and records are synthetic.

## Caption script

1. The next drilling risk may already be written down—in the report of a well drilled years ago.
2. eRTMAC shows what is happening now. Historical lessons are buried in scattered reports.
3. NWIS connects those lessons to the interval ahead—with the source beside the warning.
4. At 5 km, this synthetic demo returns one offset. Radius is a first filter, not a geology match.
5. Expand to 50 km: three offsets. Surface distance alone does not establish geological similarity.
6. Compare the reported formation intervals on a shared measured-depth scale.
7. A historical pack-off is listed 32.9 m MD ahead using approximate formation-top mapping.
8. Open marker 19 in the synthetic text report. It is not a verified physical PDF page.
9. A generated training-only PDF becomes a structured event with its physical page reference.
10. The extracted event starts in review. An engineer must explicitly approve it.
11. After review, the event can enter historical context. Its source remains attached.
12. The engineer records a decision for the active well, citing an offset-well event.
13. The handover note survives reload. Reviewer identity is self-entered, not authenticated.
14. The synthetic pack-off replay changes pressure, torque, and penetration rate. This is not live eRTMAC telemetry.
15. A labeled, uncalibrated heuristic surfaces an assessment. No incident countdown or field performance is claimed.
16. Every well leaves a lesson. The next well should not have to learn it again.
